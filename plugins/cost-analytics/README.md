# 费用分析

费用弹窗最大宽度为 800 像素，随屏幕宽度收缩并支持纵向滚动。桑基图采用细竖条节点、半透明带状连线和节点内侧标签；带宽为对数显示权重，具体费用以金额标签为准。

在 Web 界面汇总会话的请求次数、token 用量和估算费用，提供按项目、会话查看的设置页面。当前会话的费用胶囊与内置 Token 用量胶囊显示在同一行，点击后可查看费用明细。费用弹窗复用内置 Token 用量弹窗的菜单表面、标题分隔线和双列详情布局；其中的模型→请求→费用流图由随插件打包的 d3-sankey 0.12.3 排版。

依赖宿主 settings、sessionQuery 服务。价格由插件配置和用户设置决定，估算结果不等于供应商账单。插件会读取本机会话历史；不会把这些会话打包到本仓库。大规模会话库的性能和各提供者计价差异需要按实际环境验证。

从仓库根目录运行 `node scripts/install.mjs cost-analytics` 安装。此插件来自本地版本，尚未对所有 Harness 版本做兼容性验证。
