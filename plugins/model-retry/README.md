# 模型重试次数插件

独立的 Harness 插件，在「设置 → 通用设置」末尾提供模型重试次数输入框和保存按钮。默认 5，0 关闭自动重试；次数不包含首次请求。设置保存到 Harness 用户设置，刷新页面或重启后保留。保存失败显示错误。

修改从下一步模型请求生效，已开始的请求步骤保持捕获的预算。普通提供者保留原有可重试错误和退避间隔；原本无限重试的提供者改为有限重试，仅处理空响应、限流、服务器、超时和传输错误。禁用插件恢复提供者原策略。

## 安装

需要已挂载 `dsh-llm-retry`、settings 和 Web 通用设置的 Harness；本机测试版本为 `0.1.5-rc.1`。在 Web profile 安装本目录，然后向 `cordis.patch.yml` 添加：

```yaml
- insert:
    - id: ui-model-retry
      name: '@deepseek-ai/dsh-client-ui-model-retry'
```

插件可在「我的插件」里启用或禁用。挂载后刷新网页查看新增控件。

## 验证

运行 `node --test plugins/model-retry/tests/*.spec.js`。运行时集成测试使用本机 `~/.dsh/runtime` 安装的 Cordis 和重试执行插件，验证 0、1、3 次预算的日志以及卸载后恢复提供者策略。

保存成功后会在输入框下方显示“保存成功”，保存期间按钮显示“保存中…”，失败时保留错误提示。

## 模型影响与限制

每次重试可能产生额外模型费用，不增加提示词或改变消息内容。重试仍由内置执行插件记录到会话日志。直接调用 `ctx.llm.stream()` 的后台请求不经过 Agent 恢复流程，因此不受此设置影响。插件禁用或热重载后，其内存中的步骤预算捕获会清空。
